# Геометрическое ядро на C++

Учебный проект: библиотека классов для работы с треугольником и 
прямоугольником. Демонстрирует ООП, наследование, полиморфизм, 
обработку исключений и strong exception safety.

## Сборка
g++ main.cpp module.cpp -o app

## Запуск
./app

## Что реализовано
- Иерархия Triangle → Rectangle (наследование, виртуальные методы)
- Валидация координат, вырожденности, свойств фигур
- Откат состояния при неудачном изменении координат
- Ручное управление памятью (new/delete)
- Интерактивное меню

## Файлы
- `triangle.h` — структура Point и класс Triangle
- `rectangle.h` — класс Rectangle (наследник Triangle)
- `module.cpp` — реализация методов
- `main.cpp` — меню и ввод-вывод
